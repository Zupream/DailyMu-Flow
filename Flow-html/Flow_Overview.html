DAIL-74 / Fortune
11 / 19
ทำนายดวงวันนี้ — Shortcut Cards + Engines
Shortcut cards ในหน้า Today → Redirect ไป Tab ทำนาย พร้อม 3 Engines: เซียมซี, ไพ่ทาโรต์, ทำนายฝัน
SHORTCUT CARDS (หน้า TODAY)
📱 เลื่อนถึง Section ทำนาย
→
🎋 เซียมซีวันนี้
🃏 เปิดไพ่ทาโรต์
💭 ทำนายฝัน
→
🔮 Redirect → Tab ทำนาย
🎋
Engine A: เซียมซีวันนี้
Animation กระบอกเซียมซี → กดเขย่า/Shake → เซียมซีตก → แสดงเลขเซียมซี + คำทำนาย + AI Interpretation + ระดับ (ดี/กลาง/ระวัง) + ปุ่มแชร์/เขย่าใหม่
Shake / กดเขย่า
🃏
Engine B: เปิดไพ่ทาโรต์
แสดงไพ่คว่ำหน้า → เลือกเรื่องที่อยากดู(สูงสุด 3 เรื่อง) → เลือกไพ่ 3 ใบ → Animation พลิกไพ่ → ชื่อไพ่ + ภาพ + ความหมาย + AI Interpretation เชื่อมดวงวันนี้ + ปุ่มแชร์/เปิดใหม่
เลือก 3 ใบ
💭
Engine C: ทำนายฝัน
Text input "คุณฝันเห็นอะไร?" + Suggestion chips (งู, น้ำ, ปลา, เลขเด็ด) → กดทำนาย → ความหมายฝัน + AI Interpretation เชื่อมดวง + ปุ่มแชร์/ทำนายใหม่
พิมพ์ / เลือก chip
🎯 Key Rules
  • Section นี้ไม่ call API (static shortcut)
  • Cards scroll แนวนอนได้ (Scalable)
  • Engine ล่ม → ยังแสดง card แต่หน้า engine แสดง error
📊 Acceptance Criteria
  • แสดง 3 Shortcut Cards ครบ (icon + ชื่อ + subtitle)
  • กด Card → redirect ไป Tab ทำนายตรง engine
  • ทุก engine มีปุ่มแชร์ผลลัพธ์
