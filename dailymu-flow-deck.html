DAIL-30 / Authentication
04 / 13
Forgot / Reset Password
ตั้งรหัสผ่านใหม่ผ่าน Email Link พร้อม Token Validation
FLOW A: REQUEST RESET
🔑 กด "ลืมรหัสผ่าน"
→
✉️ กรอก Email
→
🔍 ตรวจ Email
Email มีในระบบ?
มี
สร้าง Reset Token (15 นาที)
ส่ง Email พร้อม Reset Link
ไม่มี
"ไม่พบอีเมลนี้ในระบบ"
CTA → สมัครสมาชิก
FLOW B: SET NEW PASSWORD
📧 เปิด Reset Link
→
🔍 ตรวจ Token
→
🔐 กรอก Password ใหม่
→
✅ สำเร็จ → Login
⚠️ Edge Cases
  • Token หมดอายุ → "ลิงก์หมดอายุ" + CTA reset ใหม่
  • Social-only user (ไม่เคยตั้ง password) → ไม่อนุญาต forgot password
  • Reset link ใช้ได้ครั้งเดียว
✅ Criteria
  • ส่ง reset link ไปที่ email ที่มี
  • แจ้งชัดเจนเมื่อ email ไม่พบ
  • Password ใหม่ใช้ login ได้ทันที

Consent: Terms & Privacy (PDPA)
ข้อตกลงและเงื่อนไขก่อนใช้งานแอป — Blocking screen ทั้งตอน Register และ Policy Update
FLOW 1: FIRST LOGIN / REGISTER
👤 Register / First Login สำเร็จ
↓
📜 แสดงหน้า "ข้อตกลงและเงื่อนไข"
↓
☑️ ติ๊ก Checkbox 2 อัน
↓
✅ กด "ยอมรับ" → เข้าหน้าหลัก
UI COMPONENTS
📋 หน้า Consent ประกอบด้วย
  • Header: "ข้อตกลงและเงื่อนไข"
  • ☑️ Checkbox 1: ยอมรับข้อกำหนดการใช้งาน + ลิงก์อ่านเพิ่มเติม
  • ☑️ Checkbox 2: ยอมรับนโยบายความเป็นส่วนตัว + ลิงก์อ่านเพิ่มเติม
  • ปุ่ม "ยอมรับ" — disabled จนกว่าติ๊กทั้ง 2
  • กรณี Policy Update: ข้อความแจ้งว่า "เราได้อัปเดตข้อกำหนด..."
💾 Data ที่เก็บ
  • consent_id, user_id, consent_version
  • terms_accepted, privacy_accepted
  • accepted_at (timestamp), ip_address
📡 /api/consent/check
→
📝 /api/consent/accept
→
📄 /api/consent/latest-policy

Birth Profile Setup
สร้างโปรไฟล์ดวงแรก — Step Form เพื่อผูกข้อมูลดวง

→

→
3️⃣ ยืนยัน & บันทึก
→

👤
Step 1: ข้อมูลพื้นฐาน
ชื่อโปรไฟล์ (max 20 ตัว), เลือก Avatar/สี, ความสัมพันธ์ (ตัวเอง/คู่รัก/ครอบครัว/เพื่อน)
Required
🔮
Step 2: ข้อมูลดวง
วันเกิด (Date picker), เวลาเกิด (Optional), ระบบดวง (ไทย/จีน/สากล)
Required + Optional
✅
Step 3: ยืนยัน
แสดง Summary → กด "ยืนยัน" → บันทึก → Redirect หน้าหลัก
Complete
💾 Data Structure
  • profile_name, avatar_color, relationship
  • birth_date, birth_time (optional)
  • horoscope_system, is_primary: true
⚠️ Note
  • โปรไฟล์แรก = primary profile
  • ใช้คำนวณดวงทุกที่ในแอป
  • สร้างเพิ่มได้ภายหลัง (max 5)
