**Dark theme ต้องปรับ CSS เพิ่มเติม (สำคัญมาก — ถ้าไม่ปรับ UI จะอ่านไม่ได้บนพื้นเข้ม):**

```css
/* Navigation bar — ต้องเป็นพื้นเข้มแทนสีขาว */
.nav-bar {
  background: rgba(15, 23, 42, 0.9);
  border-color: rgba(96, 165, 250, 0.15);
  box-shadow: 0 4px 24px rgba(0,0,0,0.4);
}

/* Navigation buttons — ต้องเห็นบนพื้นเข้ม */
.nav-btn {
  border-color: rgba(255,255,255,0.15);
  color: #94A3B8;
}
.nav-btn:hover {
  background: rgba(96, 165, 250, 0.15);
  color: #60A5FA;
  border-color: rgba(96, 165, 250, 0.3);
}

/* Dropdown menu */
.page-dropdown {
  background: rgba(15, 23, 42, 0.95);
  border-color: rgba(96, 165, 250, 0.15);
  box-shadow: 0 4px 24px rgba(0,0,0,0.5);
}
.page-dropdown-item { color: #94A3B8; }
.page-dropdown-item:hover { background: rgba(96, 165, 250, 0.1); color: #F1F5F9; }
.page-dropdown-item.active { background: rgba(96, 165, 250, 0.15); color: #60A5FA; }

/* Fullscreen button */
.fullscreen-btn {
  background: rgba(15, 23, 42, 0.8);
  border-color: rgba(96, 165, 250, 0.15);
  color: #64748B;
}

/* Cards & components — shadows เข้มขึ้น */
.card, .mini-card, .flow-step, .state-node, .agenda-item {
  box-shadow: none;
}
.card:hover, .mini-card:hover {
  box-shadow: 0 4px 16px rgba(0,0,0,0.3);
}

/* Grid background — ปรับ radial-gradient ให้เหมาะกับพื้นเข้ม */
.grid-bg::after {
  background: radial-gradient(ellipse at 50% 0%, rgba(96,165,250,0.08) 0%, transparent 60%);
}
```

## 7. 🎨 Custom

เมื่อ user ส่ง primary + secondary color มา ให้สร้าง CSS variables ตามรูปแบบด้านบน:

```
primary → primary-dark (darken 15%), primary-light (lighten 15%)
secondary → secondary-dark (darken 15%), secondary-light (lighten 15%)
bg-dark → สี pastel อ่อนมากจาก primary (opacity ~3-5%)
bg-card → rgba(primary, 0.05)
text-primary → สีเข้มที่ contrast กับ bg-dark ได้ดี
grid-color → rgba(primary, 0.06)
border-color → rgba(primary, 0.12)
```

Accent colors (orange, red, purple, pink, amber) ให้เลือกสีที่เข้ากับ primary/secondary
